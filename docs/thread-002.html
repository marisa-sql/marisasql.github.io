Building this private imageboard-style blog (no JS)

Static pages, board navigation, and a repeatable post template.

./assets/002.jpg

Goal

Make a catalog that feels like an imageboard, but with OP-only longform posts.

How it works

  • Each post is a static HTML page.
  • Board “filtering” is just separate catalog pages: sec.html, dev.html, ops.html.
  • One shared style.css makes it consistent.
